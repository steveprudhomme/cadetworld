# Sécurité

Cadet World est un répertoire statique. Seule la version courante de la branche principale est maintenue.

Pour signaler une vulnérabilité du dépôt, un lien compromis ou une divulgation de données sensibles, écrivez à [sprudhom@gmail.com](mailto:sprudhom@gmail.com?subject=Cadet%20World%20-%20securite). Décrivez le problème, son emplacement et, si possible, les étapes permettant de le reproduire. Évitez de publier les détails sensibles avant leur examen. Aucun délai de réponse garanti n’est annoncé.

Une simple correction d’adresse publique peut être proposée au moyen du modèle d’issue ou du lien « Signaler » du README. Les problèmes concernant une plateforme externe doivent également être signalés à son exploitant.
