# Méthode et provenance

La liste initiale reprend les 39 organisations et éléments nationaux cités dans la conversation « GNU Cadet World » des 5 et 6 octobre 2026, y compris les organisations dont aucun compte n’était identifié. Cette conversation sert à constituer l’inventaire, pas à prouver le caractère officiel des comptes. Les marqueurs de citation internes à cette conversation ne sont pas des sources publiques exploitables.

Les adresses Instagram et Facebook initiales ont été conservées sans paramètres de suivi. Aucun identifiant de compte inconnu n’a été inventé. Les éléments Air et Sea du NCC de Singapour restent distincts, sans duplication artificielle du compte Facebook central.

Deux enrichissements documentés ont été apportés à la liste initiale : l’Instagram de Civil Air Patrol a été corrigé de `civil__air__patrol` vers `civilairpatrol`, conformément au site national; le Facebook `NavyCadetsAUS` a été ajouté pour les Australian Navy Cadets à partir de leur site national. Les sources correspondantes figurent dans les données.

Pour cette édition, une sélection de sites institutionnels a été consultée afin de comparer leurs liens sortants aux adresses exactes du tableau. Seules les correspondances obtenues sont marquées « Source officielle ». Les autres adresses restent « À confirmer », même lorsqu’elles étaient présentées comme officielles dans la recherche initiale. Les sources publiques retenues sont enregistrées dans les données et affichées dans le tableau.

Le rapport `link-checks.json` contient un test HTTP GET de chaque adresse HTTPS publiée dans les fichiers Markdown ou dans les données. Les doublons sont testés une seule fois. Il distingue les réponses HTTP des erreurs de transport et conserve l’URL finale après redirection. Facebook et Instagram limitent fréquemment l’accès automatisé : une erreur ne suffit donc pas à retirer un compte. Une réponse 200 peut aussi être une page de connexion, et n’est pas une preuve d’identité.

La validation locale contrôle la structure du tableau, les identifiants uniques, les statuts, les domaines sociaux, l’existence des liens vers les fichiers locaux, la synchronisation du README et le décodage des objets mailto. Elle ne peut pas garantir que le logiciel de courriel de chaque visiteur est configuré.
