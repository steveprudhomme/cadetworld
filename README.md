# Cadet World

Un annuaire collaboratif des organisations de **cadets militaires et civiles dans le monde**, ainsi que de leurs comptes Instagram et pages Facebook.

Le répertoire privilégie les organisations nationales, territoriales et leurs éléments nationaux distincts : Air, Army, Sea/Navy, National Cadet Corps (NCC) et Civil Defence. Les unités locales ne sont pas incluses. Les organismes civils partenaires des échanges de cadets de l’air sont explicitement distingués des corps de cadets.

## Annuaire mondial

Cette première édition reprend les **39 organisations ou éléments identifiés dans la recherche initiale**. Elle ne constitue pas encore un inventaire mondial exhaustif. Les appellations et classifications non confirmées restent ouvertes aux corrections.

**Lecture des statuts, séparément pour Instagram (IG) et Facebook (FB) :**

- ✅ **Source officielle** : le site institutionnel consulté renvoie à cette adresse. Cela ne garantit pas l’accès à la plateforme sans connexion.
- ◐ **À confirmer** : adresse identifiée dans la recherche initiale, dont le rattachement officiel reste à confirmer dans cette édition.
- **Non identifié** : aucune adresse suffisamment établie dans la recherche initiale; cela ne signifie pas qu’aucun compte n’existe.

Dernière revue : **6 octobre 2026**. Les résultats techniques sont consignés dans le [rapport de vérification](docs/link-checks.json). Un blocage, une page de connexion ou un délai dépassé ne prouve ni la validité ni la disparition d’un compte.

Le lien **✉ Signaler** ouvre votre logiciel de courriel vers **sprudhom@gmail.com**, avec l’identifiant et le nom de l’organisation dans l’objet. Il n’envoie rien automatiquement. Si aucun logiciel n’est configuré, écrivez à cette adresse en indiquant l’identifiant CW, ou ouvrez une issue.

## Proposer une correction ou une organisation

Consultez le [guide de contribution](CONTRIBUTING.md), utilisez les modèles d’issues du dépôt ou le lien de signalement de la ligne concernée. Merci de fournir une source officielle et de privilégier les coordonnées publiques des organisations.

## Données et maintenance

Le fichier [data/organizations.json](data/organizations.json) est la source du tableau. Les identifiants CW restent stables, même si l’ordre des lignes change. Les champs de statut et les sources sont conservés séparément pour permettre une vérification progressive.

Avec Python 3.10 ou plus récent, sans dépendance externe :

```sh
python scripts/directory.py
python scripts/directory.py --check
python scripts/check_links.py
```

La première commande régénère uniquement le tableau; la deuxième vérifie les données, les liens locaux, les objets mailto et la synchronisation du README. La troisième teste les liens HTTPS et actualise le rapport, sans attribuer automatiquement un caractère officiel aux comptes.

Voir la [méthode de vérification](docs/VERIFICATION.md), le [code de conduite](CODE_OF_CONDUCT.md) et la [politique de sécurité](SECURITY.md).
